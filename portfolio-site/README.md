# Chanyong — Software Engineering Portfolio

A responsive dark portfolio for Chanyong: selected projects, skills, and internship contact.

## Featured projects

- RentMate
- AI Business Assistant
- Data Insights Platform (Flask)

## Replace the placeholders

Open `app/page.tsx` and replace:

- `YOUR_USERNAME`
- `RENTMATE_REPOSITORY`
- `AI_ASSISTANT_REPOSITORY`
- `FLASK_PROJECT_REPOSITORY`
- `YOUR_EMAIL@example.com`
- `YOUR_LINKEDIN`

You can also edit project descriptions, technologies, and contribution statements in the `projects` array near the top of that file.

## Run locally

Requirements: Node.js 18.18 or newer (20+ recommended).

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

## Main files

- `app/page.tsx` — portfolio content and page structure
- `app/globals.css` — colours, layout, animation, and responsive styling
- `app/layout.tsx` — page title, description, fonts, and favicon
- `public/favicon.svg` — browser icon
